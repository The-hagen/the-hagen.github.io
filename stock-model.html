What it is

It is a fully automated pipeline that runs on the 1st of each month. When a run finishes, the latest result is published to this website and the page updates itself, so the numbers here always come from the most recent run.

The model is a random forest (200 trees) trained on the last eight years of monthly data and about 185 inputs per stock. I compared it against a neural network and LightGBM while building it; the random forest is what the monthly run uses.

How a monthly run works

  1. Collect the dataStock prices for every company in the universe, macroeconomic series (oil and gas prices, interest rates, currencies, the VIX volatility index, and salmon and timber prices) and the latest short positions in each stock. Every download is counted, so a run that is missing part of the market can't pass as a complete one.
  2. Check that the data is completePrices have to reach the last trading day of the previous month. Anything still behind gets one more attempt. If more than 10% of stocks, or the Oslo or US benchmark index, are still missing after that, the run stops before the model is trained.
  3. Build the inputsAbout 185 measures per stock per month: momentum and reversal, volatility, liquidity, size and value, short interest, earnings timing, each stock's sensitivity to oil, interest rates and currencies, and geopolitical risk.
  4. Train the modelA random forest is trained on a rolling eight-year window, using only data that was available at each point in time. It learns to predict next month's return including dividends.
  5. Forecast and rankEvery stock gets a forecast, including stocks with gaps in their history, which are filled rather than dropped. The ten highest forecasts are the month's picks, and the ten lowest make up the bottom 10.
  6. Check and publishThe ranking is published on this page. A separate private report checks the data and the model for anything unusual, and scores how last month's picks did once that month has closed.

What is shared, and what stays private

This page shows the ranking itself: each stock's rank, sector and forecast return, which stocks are this month's picks, and the same for every earlier month.

How the model gets there stays private: the inputs, how much weight each one carries, and the diagnostics from each run. Only the fields above are allowed out, and every run checks that before anything is published.

Nothing fails quietly. If a run hits a problem, the ranking is still published, and the problem is flagged and logged so it can be fixed before the next run.

This is research code, not investment advice. The forecasts are out-of-sample, but one exchange over about a decade is a research baseline, and a ranking that looks confident can still be wrong for months at a time.
